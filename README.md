# AstaLyaVistaService

API системы ведения задач: FastAPI, SQLAlchemy и PostgreSQL.

## Сборка и запуск Docker

Нужны работающий Docker и Docker Compose. Команды выполняются из корня проекта:

```sh
docker compose up -d --build
```

Команда собирает образы и запускает PostgreSQL и API в фоне. Данные сохраняются после перезапуска контейнеров.
При неудачном старте API автоматически перезапускается, пока PostgreSQL поднимается.

Посмотреть логи и остановить сервис:

```sh
docker compose logs -f
docker compose down
```

В WSL добавляйте `sudo` к командам Docker, если доступ без него не настроен.

## Что реализовано в API

- Создание, просмотр, изменение и удаление задач: `/api/v1/tasks`.
- Смена статуса задачи: `/api/v1/tasks/{task_id}/status`.
- Фильтры по исполнителю, проекту, статусу, просроченности и открытым задачам.
- Справочники проектов и сотрудников из БД: `/api/v1/projects`, `/api/v1/employees`.
- Проверка подключения к БД: `/health`.

## PostgreSQL

Сервис `database` содержит схему и демоданные. API подключается к нему через SQLAlchemy; подключение задаётся переменной `DATABASE_URL` в Compose. ID в API передаются строками, например `"1"`; актуальные ID проектов и сотрудников доступны в справочниках.

В БД номер задачи `tasks.number` назначается автоматически: `<Код проекта>-<Порядковый номер>`, например `API-1`. Счётчик отдельный для каждого проекта; удалённые номера не используются повторно. При переносе задачи в другой проект назначается новый номер. Новому проекту нужно задать уникальный `code`; после выдачи номеров менять его нельзя.

Срок задачи — календарная дата, затраченное время — минуты. Связи сохраняются в `task_links`; при удалении задачи ссылки на неё удаляются автоматически.

На новой БД SQL-скрипты выполняются автоматически. Для существующей БД сначала соберите образ:

```sh
docker compose up -d --build database
```

Примените только ещё не выполненные обновления, каждое один раз: `02` добавляет номера, `03` — поля и связи для API. Существующие сроки в `03` преобразуются в даты по часовому поясу Europe/Moscow.

```sh
docker compose exec database psql -U taskUser -d TaskBase -v ON_ERROR_STOP=1 -f /docker-entrypoint-initdb.d/02_task_numbers.sql
docker compose exec database psql -U taskUser -d TaskBase -v ON_ERROR_STOP=1 -f /docker-entrypoint-initdb.d/03_api_storage.sql
docker compose up -d --build database-api
```

При запуске Python без `DATABASE_URL` доступен прежний мок в памяти; при недоступности настроенной БД API возвращает ошибку и не переключается на мок.

## Swagger

Вся информация по API — методы, параметры, схемы запросов и ответов — доступна в Swagger.
После запуска откройте [http://localhost:8000/docs](http://localhost:8000/docs).
Чтобы вызвать метод, нажмите **Try it out** -> **Execute**.
